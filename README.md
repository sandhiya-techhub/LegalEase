# LegalEase – AI-Powered Legal Document Generator

LegalEase is an AI-powered legal document generator that helps users create customized legal documents easily and quickly.

## Features

- Generate legal documents using Generative AI
- Supports customizable document details
- Generates editable legal documents
- Supports TXT, DOCX and PDF formats
- Simple and user-friendly interface

## Technologies Used

- Python
- FastAPI
- Streamlit
- Google Gemini AI
- python-docx
- FPDF
- Pillow

## Project Structure

- ai_core – AI document generation
- frontend – Streamlit user interface
- legalEaseAPI – FastAPI backend
- image – Project images
- config.py – Configuration
- requirements.txt – Required Python packages

## How to Run

1. Install the required packages using `requirements.txt`.
2. Configure the required environment variables.
3. Run the FastAPI backend.
4. Run the Streamlit frontend.
5. Open the application in a web browser.

## Purpose

The main purpose of LegalEase is to simplify the process of creating legal documents using Generative AI.
